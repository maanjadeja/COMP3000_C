    The reason why we are unable to view the varible MYVAR is because with the sudo command we temporarily shift
    to the role of the root user or another user if specified. The MYVAR variable can only be viewed by the user
    that is present currently logged in to the directory. This is why when we try to execute a sudo command we are
    prompted with a log in before the command executes. In order to see the MYVAR variable with the sudo command
    we have to input the command "sudo -E env" command as the -E argument allows us to pass in all the variables
    that we have set in our current environment to the sudo environment.

Q.2 The roles of the user/kernel mode and root/non-root modes are such that each mode have their own set of 
    commands that they can execute. When we input the keyword sudo, it tells the operating system to take the role
    of the root, any command that is inputted with sudo at the front without any arguments are executed, with
    the root as the current environment.
