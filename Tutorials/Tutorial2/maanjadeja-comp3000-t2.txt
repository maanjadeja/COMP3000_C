Q.1 The file hello.dynamic (16064) is smaller than hello.static (900312). As described in the questions all the 
    externel libraries dependencies are placed into the executable file, whereas, in hello.dynamic, the executable
    calls for external runtime library dependencies before creating the executable.

Q.2 The file hello.dynamic and syscall-hello.dynamic generate the most system calls, however, 
    syscall-hello.dynamic is the largest file. As described previously the dynamic files call for the external 
    libraries before creating the executable, whereas the static files add the libraries to the executable. This 
    is why the static files are larger than the dynamic files.

PART C
Q.1 When the program is referring to argv[], it is reffering to the entry that we put into the command prompt,
    when preparing to execute the file: ./3000memview. This is why the early entries in argv and envp are similiar
    to one another because they are taken from the command prompt. The lmsg has different entries, as when we input
    "&" before a variable name we are asking for its address whereas if print the pointer variable directly we get
    a different number as it is pointing to the data it's holding address. The gmsg variable also has the same 
    situation, however because it is located outside the main function, it holds a different memory address than
    the lmsg. All the variable addresses are inconsistent because they are located at different places in the 
    program, and they are holding different types of values. This is why they all have varying addresses.

Q.2 The stack is used to keep track of where the variables, functions calls, return values are placed so the 
    program flow is is not messed up. The program code is located at the top of the address space, the heap
    where all the dynamic memory is stored is stored below the program code. As we go lower, the stack it grows
    negatively, so first the global variables will be located and then at the bottom the local variables, return
    values.etc
