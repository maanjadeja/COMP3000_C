    To view the PATH variable we input "echo $PATH".

    To add a directory to the PATH variable, we can add it to the start or the end.
    To add the diretory at the start of the PATH variable we input: "export PATH=/the/file/path:$PATH".
    To add the directory at the end of the PATH variable we input:  "export PATH=$PATH:/the/file/path".
    To add multiple directories to the PATH variable we input: "export PATH=$PATH:/the/file/path:/the/file/path2".

    In order to permanently add a directory to the PATH variable, we have to use the "~/.bashrc" command if we are
    using a bash shell, or "~/.zshrc" if we are using a zsh shell. 
  
    To open the "~/.bashrc" file we input "nano ~/.bashrc". To exit the file we type "ctrl+x". 
    To permanently add a directory to the PATH variable we have to open the "~/.bashrc" file, and go to the bottom
    of the file using the down arrow key. We then add a comment like: "# Adding current directory to PATH variable".
    We then permanently add the command using: "export PATH=/the/file/path:$PATH", or 
    "export PATH=$PATH:/the/file/path", depending on whether we want to add the path at the beginning or end. At
    the end we make sure to save the file before exiting. To check if the directory has been sucessfully added,
    we then run: "echo $PATH" and check if it is present.

Q.6
    The "chmod" command allows us to change the file mode bits. This command has 2 sections:
	chmod -r - Read mode
	chmod -w - Write mode 

    There is also a combination of letters: ugoa, that allows which users will be allowed to access the particular
    file. Here:
		u - represents the user who owns the file
		g - represents other users in the files group
		o - represents other users who are NOT in the files group
		a - represents ALL users

    If none of the above letters are specified, the default is selected as "a". We can also use "+" causes the 
    selected file's mode bits to be added to existing file mode bits. The "-" cause the selected file's mode bits
    to be removed from the existing file's mode bits. The "=" causes the selected file's mode bits to be added to
    the existing file's mode bits, but any unmentioned bits are removed excluding the set user and group ID's.	

    To get the permissions of a file we need to input: "stat filename".
    Ex. stat /usr/bin/cp
